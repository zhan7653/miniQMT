# 决策 Agent（`fundlab/agent`）

`fundlab/agent` 是 JSON 决策文件契约的仓库内生产者。无论确定性策略还是 LLM
策略，进入交易内核的唯一产物仍是：

```text
data/agent/decisions/<account_id>/<YYYY-MM-DD>.json
        ↓
fundlab.strategies.FileIntentSource
        ↓
PortfolioIntent
```

Agent 不直接调用模拟内核，更不连接实盘。没有决策文件表示持有；已有但无效的文件
会失败关闭，不能降级成沉默。

## 当前策略

### `momentum-rotation`

`paper-agent` 的确定性基线。它使用点时复权收盘价计算 60 会话动量，在声明的
`risk_on` / `risk_off` 权重之间选择。历史不足、参数拼错或权重越界都不落盘。

### `dual-momentum`

`paper-dual-momentum` 的月末 ETF 轮动策略。它分别计算 `510300.SH`、`510500.SH`、
`159915.SZ`、`518880.SH` 的 60/120 会话点时复权动量并取均值，选择分数为正的前两只
等权持有；全部不为正时转为 `511010.SH`。任一声明标的历史不足时拒绝猜测。

### `inverse-volatility`

`paper-inverse-vol` 在月末按最近 60 会话年化实现波动率的倒数配置 `510300.SH`、
`511010.SH` 与 `518880.SH`，单一标的最多 60%，超出部分按剩余倒数波动率重新分配。
缺失或非正波动率会失败关闭。

### `dividend-rules`

`paper-dividend-rules` 是不调用 LLM 的红利对照组。它复用 `dividend-value` 的点时股票、
ST、流动性、连续分红与章程边界，并额外要求最近完整分红财年最多滞后两年、过去 12
个月确有现金分红，再按保守可持续股息率、分红稳定性和流动性确定性排序。每周检查，
空仓或距离上次组合决策至少 28 天时选 10 只等权配置，保留 5% 现金；持仓跌出硬筛时
可提前恢复边界，有未完成订单时保持不动。

### 价格型非 LLM 前瞻策略

以下账户只从账户创建日起进入模拟盘，不补算历史净值。原因是 Data Platform v2 已有
点时价格、成交额、停牌、ST 与涨跌停事实，但不承诺完整退市证券历史；股票横截面账户
因此明确标记 `prospective_only`，不能用当前幸存者宇宙宣称历史收益：

- `paper-risk-parity`：月末读取五只 ETF 的 120 会话对齐复权收益，以 25% 对角收缩的
  协方差求等风险贡献，单资产最多 50%；
- `paper-trend-vol`：月末保留 120 会话动量为正的风险 ETF，按 60 会话等权篮子实现
  波动率缩放至 10% 年化目标，风险仓最多 90%，余额进 `511010.SH`；
- `paper-low-beta`：月末在非 ST、上市至少 250 天、20 日平均成交额不少于 5,000 万元
  的股票中，先以20日原始价格稳定性保守预筛最多800只，再对入围者使用点时复权序列，
  按120日相对 `510300.SH` Beta 与60日波动率双排名选20只；股票仓90%，`511010.SH` 10%；
- `paper-st-removal`：周末筛选最近 60 会话由 ST 转为非 ST、20/60 日动量均为正且价格
  高于 60 日均价的股票，最多 5 只，每只固定 5%，余额进 `511010.SH`；
- `paper-st-momentum`：周末只在当前仍为 ST、60/120 日动量均为正且流动性/近期封板
  次数通过硬筛的股票中选最多 5 只，每只固定 3%，余额进 `511010.SH`。

两套 ST 账户没有候选时明确配置 100% `511010.SH`，不会为了保持股票仓位放宽筛选。
模拟内核继续负责 T+1、涨跌停阻断、参与率、滑点、费用与现金约束；真实券商的风险警示
板权限与风险揭示不由模拟账户代替。

### `crisis-drawdown`：宽基危机策略组

八个账户从启用日起前瞻运行，不补做历史回测。策略每日查看声明 ETF 的点时复权价格，
但只有状态变化才写决策文件：平时持有 `511010.SH`；出现大回撤后，反转型要求近期低点
反弹且重新站上短期均价，阶梯型则按回撤加深分批增加风险仓；建仓后以模拟账户原始成交
成本和最新可交易价格计算真实持仓收益，达到止盈线或价格恢复至事件前高附近时全部退出，
随后进入冷却期。任一声明标的缺少完整窗口、持仓缺价或存在未完成订单时均不猜测、不
叠加决策。

核心宽基池按指数暴露去重，不把多只同指数日经 ETF 当成独立分散：A 股使用
`510300.SH`、`510500.SH`、`512100.SH`、`563300.SH`、`159915.SZ`，另有
`159920.SZ`（香港）、`513500.SH`（标普 500）、`159941.SZ`（纳指 100）、
`513520.SH`（日经 225）和 `513030.SH`（德国）；`513310.SH` 中韩半导体只进入独立的
卫星账户。八个变种分别为：

- `paper-crash-cn-small`：三只 A 股 ETF 的小池，最多两只、风险仓 40%；
- `paper-crash-cn-wide`：五类 A 股宽基，最多三只、风险仓 60%；
- `paper-crash-global`：十类全球宽基，最多四只、风险仓 60%；
- `paper-crash-conservative`：至少 25% 回撤、8% 低点反弹，风险仓最多 35%；
- `paper-crash-aggressive`：15% 起触发、每再跌 7.5% 增加一档，风险仓硬上限 80%；
- `paper-crash-vol-control`：按 60 会话实现波动率把组合风险缩放至 10% 年化目标；
- `paper-crash-fast-profit`：与全球反转组对照，但持仓收益 15% 即退出；
- `paper-crash-semiconductor`：只观察 `513310.SH`，30% 回撤后确认反转，仓位最多 15%。

这些账户明确不读取净值、IOPV 或溢价率。跨境 ETF 在股灾时可能同时发生标的下跌与
溢价收缩，因此溢价不具备稳定的方向性入场含义；这类风险只通过 `position_caps` 控制，
全球组的香港、美股、日本与德国 ETF 单只最多 10%，激进阶梯组最多 15%。决策审计固定
记录 `premium_data_used: false`，不会因将来接入其他数据源而悄悄改变策略语义。

### `dividend-value`

`paper-dividend` 的红利价值 Agent，也是第一个 LLM 策略。它不是“让模型随意选股”，
而是确定性代码包围一次受限的语义排序：

1. `CanonicalMarketData` 在明确 `as_of` 下读取全股票宇宙、原始收盘/成交额和
   `known_date <= as_of` 的现金分红记录。
2. 代码排除停牌、ST、流动性不足、连续分红不足和股息率不足的股票，并分别计算
   过去 12 个月实际收现、最近完整财年、最近三个完整财年中位数和“最近完整财年与
   三年中位数取低”的保守可持续股息率。筛选与排序使用保守可持续口径，TTM 只作
   现金收现诊断，避免把跨财年集中实施或特别分红误当成持续能力。
3. 只把前 50 个合格候选、白名单资料、最近的有界记忆和当前组合事实发给 LLM。
4. LLM 必须严格返回 10 个候选 ID、逐项理由、`hold|rebalance`、对当前每只持仓的
   `retain|replace|watch` 判断、组合与基准评价、结构化行动理由和后续观察项。
5. 代码再次验证候选归属、数量、机会邮件 6% 股息率门槛、等权、5% 现金、15%
   单股上限和章程硬规则；任何越界都不生成文件、不发邮件。

当前 canonical 发布数据已覆盖至 2026-07-31，正式候选只读冒烟可形成超过 10 只的
候选池。该宇宙带幸存者偏差，因此这里只证明当前向前模拟可运行，不据此宣称历史
回测收益无偏。

## 章程与战术

`config/agents/dividend-value.yaml` 是版本化 charter（“道”），内容哈希进入评估上下文
与策略配置证据。v2 硬规则及长期原则：

- 只买股票且排除 ST；
- 连续现金分红至少 3 年，股息率不得低于 2%；
- 持仓 5–20 只，单股不超过 15%；
- 现金不少于 5%；
- 每周研究、低换手，机会可以只提示而不交易。
- 使用被动高股息基准检验组合长期表现，但短期跑输只观察；长期落后也必须同时有
  分红、估值或组合构造证据，基准表现永远不能独自触发交易。

`config/fundlab.yaml` 是可调战术（“术”）：选 10 只、至少 5 年连续分红、股息率至少
4%、20 日平均成交额至少 2,000 万元、现金 5%、候选池 50、组合变更冷却 28 天；
另配置 `159207.SZ` 为评估基准，至少积累 60 个共同交易会话后相对表现才可成为辅助
证据。构造策略时就校验“术”没有突破“道”，否则拒绝启动。

## 周度研究与组合变更

每日脚本仍会在发布前后调用 `agent decide --all`，但 dividend 策略只有在当前
`as_of` 是该自然周最后一个开市日时才评估（通常周五；节假日周可为周四）。同一
ISO 周、同一配置哈希的评估记录存在后，后续调用幂等跳过。

LLM 每周都要独立评价组合、基准和每只当前持仓，但只有以下情况允许写新组合决策：

- 账户尚未建仓；
- 当前持仓违反 charter，代码要求退出/恢复边界；
- 距离上一份组合决策至少 28 天，LLM 建议 `rebalance`，并给出通过代码守卫的结构化
  行动理由。

有未完成订单时不叠加新组合。冷却期内发现的机会仍可发邮件，但不调仓。持仓违反
硬规则时，代码可以用 LLM 已严格选出的合格篮子强制恢复边界，即使模型建议 hold。

## 159207 基准与迭代闭环

`159207.SZ`（高股息 ETF）只是一条被动参照线，不进入 10 只股票组合，也不会创建
第二个模拟账户。比较从组合首次实际持有股票的交易会话开始；此前纯现金等待数据或
订单的阶段不计入相对收益。组合起点使用首次建仓前一个已发布检查点的 NAV，基准以
首次建仓会话的点时复权开盘价起算，随后比较共同会话的复权收盘价。ETF 现金分配由
复权序列计入总回报；组合一侧使用扣除实际模拟费用与滑点后的 NAV。

每次周度评审会把以下事实写入追加式记忆并反馈给下一次 LLM：组合与基准累计收益、
最大回撤、超额收益、共同交易会话数，以及相对上次评审的区间表现。LLM 必须说明它
如何理解这些事实、逐只判断现有持仓并留下观察项，但代码执行以下不可绕过的边界：

- 少于 60 个共同交易会话：相对表现为 `diagnostic_only`，不能支持调仓；
- 达到 60 个共同交易会话：相对表现为 `supporting_evidence`，仍不能作为唯一行动理由；
- `persistent_benchmark_lag` 单独出现时一律转为 hold；只有同时存在分红证据变化、估值/
  排名变化、组合构造问题等独立理由，才可能继续进入冷却期和组合校验；
- 减分红、charter/硬筛违规等风险仍可立即处理，不等待 60 个会话；
- 基准缺数或计算失败会留下风险记录并进入现有告警路径，但不阻断日常账户运行。

账户页从记忆读取最新基准卡片，并在组合净值图上叠加周度评审时保存的“159207 含
分红基准”比较点。它展示的是评审证据，不是另一套可交易或可自动切换的策略。

## Responses 中转契约

配置与当前 Codex provider 对齐：`gpt-5.6-sol`、OpenAI-compatible Responses 协议、
`medium` reasoning、`max_output_tokens=32768`、300 秒超时、瞬时失败最多重试两次。
实际请求固定为：

```text
POST <agent.llm.base_url>/responses
Authorization: Bearer $FUNDLAB_LLM_API_KEY
Content-Type: application/json; charset=utf-8
```

请求使用 `store: false`；结构化输出按 Responses API 放在 `text.format`，而不是旧的
`response_format`。详见 OpenAI 的
[Responses Structured Outputs 迁移说明](https://developers.openai.com/api/docs/guides/migrate-to-responses#6-update-structured-outputs-definitions)。

响应只接受 `status=completed` 且恰好一个正式
`output[].content[].type=output_text`；拒绝、非 JSON、schema 字段变化、候选越界均失败。
不解析 Markdown 代码块，不从自由文本提取 JSON，也不降级到另一个模型或协议。

## 资料库、记忆与邮件

- **资料库**：`data/agent/library/` 下仅 `.md`/`.txt`，且必须在
  `agent.library.documents` 明确列名；每份最多 40,000 字符，总计最多 120,000。
  内容作为不可信引用数据，模型提示明确禁止执行其中的指令。
- **记忆**：`data/agent/memory/<account>.jsonl` 追加记录评估、模型/response ID、token
  用量、上下文哈希、选择理由、逐持仓判断、观察项、基准证据、决策落盘和邮件结果。
  输入只取最近 20 条，并继续受单条 20,000、总计 120,000 字符限制。损坏的 JSONL
  不会被静默喂给模型。
- **并发**：每账户跨进程文件锁包围完整评估，避免计划任务与手动 Web/CLI 同时调用
  LLM 或重复发信；交易决策文件另有原子无覆盖写入保护。
- **覆盖为持有**：显式 `--overwrite` 后的新评估若为 hold，会把原有未来决策原子移到
  `decisions/.superseded/` 留存，而不是让旧文件继续被内核执行；dry-run 只报告将发生
  该动作，不移动文件。未实际完成周度评估的 cadence skip 会保留旧决策并明确报告。
- **邮件**：只有通过代码复核的新机会/风险才进入邮件；证据哈希已成功发送过则不
  重复。机会需保守可持续股息率至少 6%，持仓硬规则风险不受此门槛限制。邮件正文
  同时附上本次基准比较和模型评价。SMTP 失败不会撤销已验证的交易决策。

所有秘密只来自环境变量：

```text
FUNDLAB_LLM_API_KEY
FUNDLAB_SMTP_HOST
FUNDLAB_SMTP_PORT       # 可选，默认 465 / SSL
FUNDLAB_SMTP_USER
FUNDLAB_SMTP_PASSWORD
```

## 启用状态

十七个非 LLM Agent 策略账户均已加入 `daily.accounts`，并以 `scheduled: true` 的默认值
接入 `agent decide --all`；月末/周末之外以及危机状态未变化时策略显式返回 hold，不生成
无意义文件。

八个 `crisis-drawdown` 账户的正式非 dry-run 评估还会先进入独立证据库
`data/agent/evaluations/<account>/<evidence-date>/<revision-id>.json`。身份绑定账户、数据日、
目标交易日、canonical 快照、策略配置和组合状态；完全相同的正式评估幂等，同日快照
修正、配置变化或状态变化生成不可变修订，旧版本不覆盖。证据先于可执行决策发布，
因此评估证据无法原子写入或严格回读时，该危机账户失败即持有，其他账户仍由
`decide_all` 隔离推进。dry-run、Web 预演和测试不写正式历史。

Web 的只读“策略监控”页从证据库投影回撤、反弹、恢复率、均线确认和波动率；只在
数据日及快照同时匹配当前 canonical 头时标为“当前”。最近一次正式评估失败时，旧的
成功记录仅作为历史显示。页面把策略信号、决策文件和模拟账户持仓分层，并将任何
非 `crisis-drawdown-v*` 决策永久标记为该账户路径含人工干预。策略阈值和 ETF 池仍只
从 `config/fundlab.yaml` 读取，Web 不提供修改入口。

`paper-dividend` 已加入模拟账户，并在真实中转预演和本地决策校验通过后设为
`scheduled: true`。`agent decide --all` 每周最后一个交易日调用外部模型；其他交易日
返回 hold，不产生模型费用。需要重新验证中转兼容性时运行：

```powershell
uv run fundlab agent decide --account-id paper-dividend --force-review --dry-run
```

这会真实调用中转并完整验证结果，但不写决策、记忆或邮件。需要人工提前评估时可去掉
`--dry-run` 做一次投递。Web API 同样支持 body 字段 `force_review`；仪表盘提供
“忽略周度节奏，立即评估”复选框。

CLI 完整接口：

```text
fundlab agent decide (--account-id X | --all)
  [--target-date D] [--overwrite] [--dry-run] [--force-review]
```

`--force-review` 只允许单账户 review-cadence 策略；`--all` 只执行
`scheduled: true` 的策略。

## 明确延期

本期不抓取新闻，不启用 hosted web search，也不让 Agent 修改 charter、战术参数或
提示词。这里的“迭代”是每周读取真实组合反馈、基准证据和既往记忆后重新作出受约束
判断，不是让模型自行改写策略或追逐短期排名。
